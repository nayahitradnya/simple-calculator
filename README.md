# Interactive Web Calculator

A clean, responsive web-based calculator built with semantic HTML5, custom CSS layout techniques, and JavaScript. This project was made
to fulfill my 2nd assignment for the Computational Thinking Class WI1102 on the topic of Algorithmic Thinking. 

## 📌 Preview
* **Header:** Displays the project title, author's name, and student identification number (NIM) using custom typography (*Tilt Warp*).
* **Interface:** Soft teal and pink theme with intuitive button layouts for fast arithmetic operations.

---

## ✨ Key Features
- **Basic Arithmetic:** Supports addition, subtraction, multiplication, and division.
- **Clear Functionality:** Dedicated clear button (`C`) to reset calculations.
- **Responsive Layout:** Designed with CSS Flexbox to ensure vertical alignment and centering across screens.
- **Custom Typography:** Integrated with Google Fonts (`Tilt Warp` and `Montserrat`).

---

## 🛠️ Tech Stack
- **HTML5:** Semantic structure and form controls.
- **CSS3:** Custom styling, CSS Flexbox for alignment, and gradients.
- **JavaScript (ES6+):** Dynamic event handling and mathematical calculations.

---

## 📁 File Structure

```text
├── index.html   # Main HTML markup structure
├── style.css    # Styling, custom fonts, and Flexbox layouts
└── index.js     # JavaScript logic for button interactions and math operations
```

## 🚀 Getting Started

To view or run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/calculator-app.git
   ```
2. **Navigate into the project folder:**
   ```bash
   cd calculator-app
   ```
3. **Open the application:**
   Open `index.html` directly in your favorite browser, or use a live server extension in VS Code.
